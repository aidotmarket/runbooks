Candidate: `683dfc82d542ed45173cd8fbde53e254b2be263c`. This is an independently inspected source finding, not a live exploit or an executable regression result. No provider request, product edit or product test was made for this diagnosis. Mars acknowledged it in bus4234 after alert4233 and included it in the next MP's existing F4 scope.

## Exact evidence

`app/services/order_service.py` SHA256 `8043a9e285594b311c35d629c0d3ff71b8d0cf08db4364fe390f1a4ef4f2cf5f`:

- Lines283–331 verify purchased-version existence, listing binding, authority kind and allowed version status. They do not enforce order expiry or download limits.

- Lines403–435 implement full download admission, including the order access window and correct `None` versus zero limit semantics.
- Lines514–568 build signed S3 URLs. Lines531–536 resolve authority and assume the seller role; lines558–564 presign the object. Neither operation is protected by an expiry/count check inside this helper.

## Required correction and proof

Keep this within the already approved orders endpoint and OrderService files. Before any non-device S3 credential builder is called, enforce the existing complete admission policy against authoritative order state. An informational GET may return unavailable metadata, but must not issue or expose a credential after refusal. Preserve zero limits explicitly. A positive available purchase must still work without accidental consumption from a mere metadata request.

MP must author before/after tests using the actual GET route, migrated PostgreSQL state and the real admission/helper path. Mock only the external role/presign boundary, record every attempt, and prove zero attempts and no returned credentials for expired, zero-limit and exhausted purchases; cover delivered/completed and partial-refund paths as applicable. Include a positive available purchase and unchanged counters. These requested tests are not yet reported as executed.

The reference public-URL branch at lines587–629 has distinct existing semantics (`downloads_remaining: null`). Assess and retain that explicit product contract; do not silently impose non-reference download counting on it.
